# Logo

Ein offener Ring (Open Source) um eine Achtelnote (die Etüde), im Verlauf der Handfarben der App:
Orange (linke Hand) zu Blau (rechte Hand). Schrift: Inter (wie in der App), in Pfade umgewandelt.

| Datei | Verwendung |
|---|---|
| `openetude-icon.svg` | quadratisch: App-Icon, GitHub-Organisation, Favicon |
| `openetude-logo.svg` | mit Schriftzug, auf dunklem Hintergrund |
| `openetude-logo-hell.svg` | mit Schriftzug, für helle Seiten |
